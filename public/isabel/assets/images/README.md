# Fotografías

Coloca aquí los archivos con **estos nombres exactos** (JPG o WebP). No hace falta editar el HTML: si el archivo existe, la foto aparece sola.

| Archivo | Dónde se ve |
|---|---|
| `hero.jpg` | Portada |
| `tortas.jpg` | Tortas personalizadas |
| `pasteles.jpg` | Pasteles y tartas |
| `galletas.jpg` | Galletas |
| `alfajores.jpg` | Alfajores |
| `amasanderia.jpg` | Amasandería |
| `brownies.jpg` | Brownies |
| `otros.jpg` | Otros productos |
| `eventos-1.jpg` | Eventos (foto principal) |
| `eventos-2.jpg` | Eventos (detalle) |
| `banqueteria-1.jpg` a `banqueteria-6.jpg` | Banquetería (galería de 3 columnas y 2 filas) |
| `nosotros.jpg` | Nosotros |

Recomendado: ~1600 px de ancho, WebP o JPG, menos de 300 KB. Si usas `.webp`, cambia la extensión también en `index.html` (`data-src`).

Logotipo usado en el sitio: `assets/logo/logoisabel.png`.
